---
title: The page keeps time with the voices
date: 2026-11-08
area: ui
issues: [50]
---
- With Voice on, the page plays the voice clip the game has already made for each line, so a line starts sooner. If no clip has come within about a second, the page asks for one as before.
- The page tells the game how far the voices have got. While they are behind, a player waits a moment before speaking again, so the talk keeps pace with what you hear. Votes and night choices never wait.
- A small "keeping time" mark next to the Voice button shows when this is working.
- Mute or turn Voice off and the game stops waiting for the voices at once. With the page closed, the game plays at its usual pace.
