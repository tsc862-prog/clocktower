---
title: "The table waits for the voices"
date: 2026-11-08
area: infra
issues: [50]
---
- With the voice on, each line said at the table now has its recording made the moment it is said, in that seat's voice, so it is ready when the page gets to it.
- While the voices are still reading earlier lines, the seats hold off speaking; the game follows the voices line by line instead of piling up. A seat never waits more than half a minute.
- With the page closed, the voice off or muted, nothing changes: the game runs at the same pace as before. The page itself still has to learn to report what it has heard, which comes with its next update.
