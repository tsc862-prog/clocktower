- Nothing you will notice in a game yet: every pull request now runs the repo rules (a patch note for you on each one, sound workflow files, every check wired into CI) and the rights check (no official name in any tracked file), and merges only when they pass.
- If a merge ever breaks the main branch, an issue called "main is red" opens by itself and stops further merges until it closes.
- The project has its dependencies and an example environment file; keys stay in your own .env and are never printed.
